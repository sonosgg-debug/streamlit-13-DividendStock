# 한국 및 미국 증시 배당주 TOP 100 대시보드

한국 증시(KOSPI, KOSDAQ)와 미국 증시(S&P 500, NASDAQ)의 배당주 종목을 배당수익률 기준으로 발굴하고, 배당 안전성, 4분면 매트릭스, DRIP 복리 시뮬레이션을 통해 심층 분석하는 전문 웹 대시보드 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

1. **4대 핵심 증시 지원 (사이드바 시장 선택)**
   - `KOSPI`, `KOSDAQ`, `S&P500`, `NASDAQ` 시장을 원클릭으로 손쉽게 전환
   - 시장별 배당수익률(Dividend Yield) 기준 **상위 100개 종목 리스트** 제공

2. **통화(Currency) 및 지표 자동 최적화**
   - **한국 주식**: 원화(₩) 표기, 주가/배당금 `#,##0원`, 시가총액 `#,##0억원`
   - **미국 주식**: 달러($) 표기, 주가/배당금 `$#,##0.00`, 시가총액 `$#,##0.0M`
   - 9대 필수 헤더: `순위`, `종목명`, `시장`, `업종`, `시가총액`, `현재가`, `배당금(DPS)`, `배당수익률(%)`, `배당성향`

3. **배당주 투자 전문가 관점의 가치 지표**
   - **배당 안전성 등급 (Safety Score)**:
     - 🟢 안전: 배당성향 10%~75%의 건전한 이익 기반 배당
     - 🟡 보통: 고배당 리츠 또는 배당성향 75%~100%
     - 🔴 주의: 배당성향 > 100% 또는 적자 기업의 배당 함정(Dividend Trap) 경고
   - **배당주기**: 연배당, 분기배당, 월배당(리츠/BDC 등) 구분

4. **인터랙티브 종목별 상세 비교 및 시각화**
   - 상단 테이블의 행을 클릭하면 하단 상세 영역과 실시간 자동 연동
   - **차트 1: 주가 및 이동평균선 추이** (20일, 60일 이평선 및 기간 밴드)
   - **차트 2: 과거 연도별 배당금(DPS) 및 배당 성장률** (바 차트 + 전년대비 성장률 라인)
   - **차트 3: 배당수익률 vs 배당성향 4분면 매트릭스** (이상적 고배당, 배당성장형, 배당함정 구역 시각화)
   - **차트 4: 배당 재투자(DRIP) 10년 복리 시뮬레이터** (투자금 설정 시 배당 재투자 복리 자산 곡선)
   - **전문가 종합 배당 진단 카드**: 배당 매력도, 지속 가능성, 현금흐름 전략 제언

5. **서식 적용 엑셀(.xlsx) 다운로드**
   - 다크 헤더(`#1E293B`), 통화별 셀 서식, 열 너비 자동 최적화가 적용된 보고서 다운로드

## 🚀 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 대시보드 실행
- **Windows**: `run_app.bat` 더블 클릭
- 또는 터미널에서:
```bash
streamlit run app.py
```
브라우저에서 `http://localhost:8501`이 자동으로 열립니다.
